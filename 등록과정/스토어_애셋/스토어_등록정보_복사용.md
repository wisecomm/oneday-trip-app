## 1. 기본 스토어 정보

### [앱 이름] (최대 30자)
- **한국어 (기본)**: `하루여행`
- **영어 (English)**: `OneDay Trip`
- **일본어 (日本語)**: `ワンデイトリップ`
- **중국어 (简体中文)**: `一日游`
- **중국어 (繁體中文)**: `一日遊`

### [간단한 설명] (최대 80자)
> 대한민국 구석구석 알짜 여행지와 최적의 당일치기 코스를 추천하는 한국 여행 필수 지도 앱

### [자세한 설명] (최대 4,000자)
```text
대한민국 곳곳의 숨은 명소와 맛집을 찾는 가장 스마트한 방법, 한국 여행 필수 코스 지도 서비스 '하루여행 (OneDay Trip)'입니다.

주말 나들이, 서울/수도권 골목 투어, 전국 당일치기 여행까지!
방대한 한국 여행 정보와 관광 빅데이터를 기반으로 현재 내 위치 주변 가볼 만한 곳을 한눈에 찾고, 이동 동선 낭비 없는 완벽한 하루 코스를 추천해 드립니다.

[주요 기능]
1. 🇰🇷 알짜배기 한국 여행 정보 및 주변 탐색
- 전국 명소, 로컬 맛집, 감성 카페, 문화 유적지 등 테마별 장소 필터링
- 도보 및 대중교통 이동 시간과 주변 편의시설 실시간 확인

2. 🗺️ 원클릭 여행 코스 완성 & 동선 최적화
- 마음에 드는 한국 여행 명소를 담기만 하면 최적의 여행 루트 자동 계산
- 이동 거리와 시간을 최소화하는 효율적인 당일치기 동선 설계

3. 📍 테마별 추천 여행 코스 제공
- '서울 핫플레이스 골목 투어', '근교 힐링 당일치기', '전통과 현대가 어우러진 문화 탐방' 등 엄선된 한국 테마 코스 제공
- 검증된 인기 코스를 그대로 내 여행에 추가하여 간편하게 여행 시작

4. 🚶‍♂️ 네이버 지도 길찾기 완벽 연동
- 앱 내에서 네이버 지도 도보/차량 길찾기로 원클릭 연결되어 길 찾기 스트레스 제로

5. 🌐 글로벌 관광객을 위한 4개 국어 다국어 지원
- 한국을 여행하는 외국인 관광객을 위한 한국어, 영어(English), 일본어(日本語), 중국어(简体/繁體) 지원 및 시스템 언어 자동 감지

대한민국 구석구석, '하루여행'과 함께 오늘 바로 설레는 여행을 떠나보세요!
```

## 2. 데이터 보안 (Data Safety) 입력 가이드 (★ 핵심 심사 항목)

구글 플레이 심사에서 가장 중요한 데이터 보안 설문 작성 가이드입니다:

| 항목 | 질문 | 권장 답변 | 상세 사유 |
| :--- | :--- | :--- | :--- |
| **위치 데이터** | 앱에서 대략적인 위치를 수집/공유하나요? | **예 (수집)** | `ACCESS_COARSE_LOCATION` 사용 |
| | 앱에서 정확한 위치를 수집/공유하나요? | **예 (수집)** | `ACCESS_FINE_LOCATION` 사용 |
| | 위치 데이터를 다른 조직과 공유하나요? | **아니요** | 외부 제3자 공유 없음 |
| | 위치 데이터가 일시적으로 처리되나요? | **예** (또는 아니요) | 실시간 주변 장소 쿼리용 |
| | 수집 목적은 무엇인가요? | **앱 기능** 체크 | 주변 명소 및 음식점 표시 목적 |
| | 암호화되어 전송되나요? | **예** | HTTPS 암호화 전송 |
| | 사용자가 데이터 삭제를 요청할 수 있나요? | **예** | 계정 탈퇴 시 삭제 지원 |
| **계정/개인정보** | 이메일 주소, 이름을 수집하나요? | **예 (수집)** | 소셜 로그인(구글 등) 사용자 식별용 |
| | 수집 목적은 무엇인가요? | **계정 관리, 기능** | 로그인 및 내 여행 코스 저장용 |
