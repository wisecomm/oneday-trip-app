# 📱 하루여행 (OneDay Trip) 구글 플레이스토어 등록정보 복사용 텍스트

구글 플레이 콘솔([Google Play Console](https://play.google.com/console)) 등록 시 그대로 복사하여 붙여넣으실 수 있도록 정리된 텍스트 및 설정 가이드입니다.

## 1. 기본 스토어 정보

### [앱 이름] (최대 30자)
- **한국어 (기본)**: `하루여행`
- **영어 (English)**: `OneDay Trip`
- **일본어 (日本語)**: `ワンデイトリップ`
- **중국어 (简体中文)**: `一日游`
- **중국어 (繁體中文)**: `一日遊`

### [간단한 설명] (최대 80자)
> 내 위치 주변 가볼 만한 곳과 최적의 당일치기 여행 코스를 추천하는 스마트 여행 지도 서비스

### [자세한 설명] (최대 4,000자)
```text
위치 기반 당일치기 여행 일정 및 맛집 지도 서비스, '하루여행 (OneDay Trip)'입니다.

주말이나 휴일, 어디로 떠날지 고민이신가요? 
하루여행은 현재 내 위치를 기반으로 주변의 알짜배기 명소와 엄선된 맛집, 감성 카페를 한눈에 지도에서 탐색하고 최적의 동선으로 여행 코스를 완성해 드립니다.

[주요 기능]
1. 실시간 내 위치 주변 추천 탐색
- 밥집, 카페, 술집, 명소 카테고리별 마커 필터링
- 도보 및 대중교통 이동 시간 실시간 확인

2. 원클릭 여행 동선 및 코스 완성
- 마음에 드는 장소를 담기만 하면 최적의 여행 루트를 자동으로 계산
- 여행지 간 이동 거리와 동선 낭비 없는 효율적인 당일치기 계획

3. 테마별 추천 여행 코스
- '성수동 반나절 카페 투어', '서울 걷기 좋은 골목길' 등 다양한 테마 코스 제공
- 남이 다녀온 검증된 하루 코스를 그대로 내 여행에 추가

4. 네이버 지도 길찾기 완벽 연동
- 앱 내에서 네이버 지도 도보/차량 길찾기로 원클릭 연결되어 길을 잃지 않는 편리함

5. 4개 국어(한국어, 영어, 일본어, 중국어) 다국어 지원
- 글로벌 여행객을 위한 시스템 언어 자동 감지 및 완벽한 로케일 대응

지금 '하루여행'과 함께 가벼운 발걸음으로 설레는 하루를 떠나보세요!
```

## 2. 데이터 보안 (Data Safety) 입력 가이드 (★ 핵심 심사 항목)

구글 플레이 심사에서 가장 중요한 데이터 보안 설문 작성 가이드입니다:

| 항목 | 질문 | 권장 답변 | 상세 사유 |
| :--- | :--- | :--- | :--- |
| **위치 데이터** | 앱에서 대략적인 위치를 수집/공유하나요? | **예 (수집)** | `ACCESS_COARSE_LOCATION` 사용 |
| | 앱에서 정확한 위치를 수집/공유하나요? | **예 (수집)** | `ACCESS_FINE_LOCATION` 사용 |
| | 위치 데이터를 다른 조직과 공유하나요? | **아니요** | 외부 제3자 공유 없음 |
| | 위치 데이터가 일시적으로 처리되나요? | **예** (또는 아니요) | 실시간 주변 장소 쿼리용 |
| | 수집 목적은 무엇인가요? | **앱 기능** 체크 | 주변 명소 및 음식점 표시 목적 |
| | 암호화되어 전송되나요? | **예** | HTTPS 암호화 전송 |
| | 사용자가 데이터 삭제를 요청할 수 있나요? | **예** | 계정 탈퇴 시 삭제 지원 |
| **계정/개인정보** | 이메일 주소, 이름을 수집하나요? | **예 (수집)** | 소셜 로그인(구글 등) 사용자 식별용 |
| | 수집 목적은 무엇인가요? | **계정 관리, 기능** | 로그인 및 내 여행 코스 저장용 |
