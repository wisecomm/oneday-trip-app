# 02. 애플 앱스토어(Apple App Store) 등록 절차 가이드

이 문서는 추후 하루여행 iOS 앱(`kotWebviewIos` 기반 등)을 Apple App Store에 출시할 때 필요한 전체 등록 절차를 정리한 가이드입니다.

---

## 📌 1. 사전 준비물

| 항목 | 규격 및 내용 | 비고 |
| :--- | :--- | :--- |
| **개발자 계정** | Apple Developer Program 계정 (연간 $99 / 129,000원 결제) | D-U-N-S 번호(기업) 또는 개인 신원 인증 필요 |
| **Mac & Xcode** | macOS 환경 및 최신 Xcode 설치 | 아카이브(Archive) 및 업로드 필수 |
| **개인정보처리방침 URL** | 웹에 게시된 공개 URL | App Store Connect 필수 입력 |
| **스크린샷** | 6.7형(1290x2796) 및 6.5형(1242x2688) 필수 | 앱 내 실제 화면 캡처본 (최소 1장 ~ 최대 10장) |
| **심사용 테스트 계정** | 아이디 / 비밀번호 / 로그인 안내 메모 | 심사관이 직접 로그인 테스트를 진행함 |

---

## 🚀 2. 단계별 등록 절차

### 1단계: Apple Developer 포털 설정
1. [Apple Developer](https://developer.apple.com/account) 로그인
2. **Certificates, Identifiers & Profiles**:
   - **Identifiers**: App ID 등록 (예: `kr.co.softone.onedaytrip`)
   - **Capabilities**: 필요 시 Push Notifications 등 체크
   - **Certificates**: Apple Distribution 인증서 생성
   - **Provisioning Profiles**: App Store 배포용 프로파일 생성

---

### 2단계: App Store Connect 앱 생성
1. [App Store Connect](https://appstoreconnect.apple.com) 접속 ➔ **[나의 앱]**
2. 좌측 상단 **[+] ➔ [신규 앱]** 클릭:
   - **플랫폼**: `iOS`
   - **이름**: `하루여행` (또는 `하루여행 - OneDay Trip`)
   - **기본 언어**: `한국어`
   - **번들 ID**: 1단계에서 등록한 App ID 선택
   - **SKU**: 내부 식별 코드 (예: `onedaytrip-001`)
   - **사용자 접근 권한**: `전체 접근 권한`

---

### 3단계: 앱 정보 및 스토어 등록정보 입력

1. **앱 정보**:
   - 카테고리: `여행` (보조: `라이프스타일` 또는 `식음료`)
   - 콘텐츠 이용 등급 설문 완료 (연령 등급 결정)
2. **가격 및 사용 가능 여부**:
   - 가격: `무료`
   - 배포 국가/지역: 대한민국 (또는 전체 국가)
3. **버전 정보 작성**:
   - **프로모션 텍스트** (선택)
   - **설명**: 앱 소개 및 주요 기능 나열
   - **키워드**: `여행,지도,맛집,당일치기,일정,코스추천,네이버지도` (콤마 구분, 최대 100자)
   - **지원 URL / 마케팅 URL**: 웹사이트 주소
   - **스크린샷 업로드**:
     - 6.7형 디스플레이 (iPhone 15/14 Pro Max 규격)
     - 6.5형 디스플레이 (iPhone 11 Pro Max / XS Max 규격)

---

### 4단계: Xcode에서 아카이브(Archive) 및 업로드

1. Xcode에서 프로젝트 열기
2. 상단 타겟 디바이스를 `Any iOS Device (arm64)`로 선택
3. 메뉴: **[Product] ➔ [Archive]**
4. 아카이브 완료 후 Organizer 창에서:
   - **[Distribute App]** ➔ **[App Store Connect]** 선택
   - 서명 인증서 및 프로비저닝 프로파일 자동/수동 선택
   - **[Upload]** 클릭하여 전송
5. 약 10~30분 후 App Store Connect에 빌드가 처리 완료 상태로 표시됨

---

### 5단계: 앱 심사 정보 입력 및 제출

1. **앱 개인정보 보호 (App Privacy)**:
   - 수집하는 데이터 질문 응답:
     - 위치 (정확한 위치, 대략적인 위치) ➔ 앱 기능 목적
     - 사용자 식별자 (로그인 시)
2. **심사 정보**:
   - **로그인 정보**: 테스트 계정 ID / PW 제공
   - **연락처 정보**: 이름, 이메일, 전화번호 (+82 10-XXXX-XXXX)
   - **메모**: 심사관에게 전할 말 (예: "위치 권한은 주변 관광지 추천 및 지도 경로 안내에 사용됩니다.")
3. 우측 상단 **[심사에 추가] ➔ [심사 제출]** 클릭

---

### ⚠️ 애플 앱스토어 웹뷰 앱 주의사항 (Guideline 4.2 방지)
- **가이드라인 4.2 (최소한의 기능 - Minimum Functionality)**:
  - 단순 웹사이트를 틀만 씌운 형태(단순 웹뷰)는 애플 심사에서 거절될 확률이 높습니다.
  - 하루여행 앱처럼 **네이티브 위치 권한(GPS) 연동, 네이티브 알림/토스트, 뒤로가기 제어, 외부 지도 앱 딥링크** 등의 기능이 반드시 동작해야 통과됩니다.
