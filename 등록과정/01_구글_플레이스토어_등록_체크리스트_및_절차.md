# 01. 구글 플레이스토어(Google Play Store) 등록 절차 & 체크리스트

이 문서는 **하루여행 (OneDay Trip)** 안드로이드 앱(`kr.co.softone.onedaytrip`)을 구글 플레이 콘솔에 등록하고 심사를 통과하여 출시하기까지의 전체 과정을 정리한 가이드입니다.

---

## 📌 1. 사전 준비물 (사전 체크리스트)

| 항목 | 규격 및 내용 | 비고 |
| :--- | :--- | :--- |
| **개발자 계정** | Google Play Console 계정 (최초 등록비 $25 결제) | 2023년 11월 이후 개인 계정은 **20명 테스터 14일 테스트** 필수 |
| **AAB 파일** | `app-release.aab` (Android App Bundle) | `./gradlew bundleRelease`로 생성 |
| **개인정보처리방침 URL** | 웹에 게시된 공개 URL (예: `https://oneday-trip.vercel.app/privacy`) | 위치 권한, 계정 정보를 다루므로 필수 |
| **앱 아이콘** | 512 x 512 px, PNG (32비트), 최대 1MB | 투명 배경 불가, 모서리 둥글림 구글 자동 처리 |
| **그래픽 이미지** | 1024 x 500 px, PNG 또는 JPEG, 최대 15MB | 스토어 상단 배너 이미지 (텍스트 최소화 권장) |
| **휴대전화 스크린샷** | 최소 2장 ~ 최대 8장 (16:9 또는 9:16 비율, 최소 320px ~ 최대 3840px) | 실제 구동 화면 (지도, 일정, 추천 피드 등) |
| **심사용 테스트 계정** | 테스트용 이메일 / 비밀번호 | 비회원 둘러보기가 가능하나, 계정 로그인 정보 제공 권장 |

---

## 🚀 2. 단계별 등록 절차

### 1단계: Google Play Console에서 새 앱 생성
1. [Google Play Console](https://play.google.com/console) 로그인
2. 우측 상단 **[앱 만들기]** 버튼 클릭
3. 기본 정보 입력:
   - **앱 이름**: `하루여행` (다국어 스토어 등록정보에서 영어: `OneDay Trip`, 일본어: `ワンデイトリップ`, 중국어: `一日游` 별도 추가 가능)
   - **기본 언어**: `한국어(ko-KR)`
   - **앱 또는 게임**: `앱`
   - **무료 또는 유료**: `무료`
4. 선언문(개발자 프로그램 정책 동의) 체크 후 **[앱 만들기]** 클릭

---

### 2단계: 대시보드 필수 작업 설정 (앱 설정 10단계)

대시보드의 **"앱 설정"** 메뉴에 있는 각 설문 및 정책을 완료해야 프로덕션 출시가 가능해집니다.

1. **개인정보처리방침**:
   - 개인정보처리방침 웹페이지 URL 입력 후 저장
2. **앱 액세스 권한**:
   - `일부 또는 모든 기능이 제한됨` 선택 후 테스트 계정 정보(아이디/비밀번호) 입력 (심사관이 로그인 기능을 테스트할 수 있어야 함)
3. **광고**:
   - `아니요, 앱에 광고가 포함되어 있지 않습니다` 선택
4. **콘텐츠 등급**:
   - 설문 시작 ➔ 이메일 입력 ➔ 카테고리: `유틸리티/생산성/기타(여행)` 선택 ➔ 폭력성, 선정성 등 질문에 모두 '아니요' 체크 ➔ 등급 산출(전체이용가) 후 저장
5. **타겟층 및 콘텐츠**:
   - 타겟 연령대: `만 18세 이상` (또는 만 13세 이상) 선택 ➔ 어린이의 관심을 끌 수 있는지 여부: `아니요`
6. **뉴스 앱**:
   - `아니요`
7. **코로나19 접촉자 추적 앱**:
   - `아니요`
8. **데이터 보안 (Data Safety) ★ 중요 ★**:
   - 위치정보(`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`)를 사용하므로 반드시 정직하게 체크:
     - **위치**: 대략적인 위치, 정확한 위치 수집 체크 ➔ 수집 목적: `앱 기능(지도 및 주변 여행지 탐색)` ➔ 암호화 전송: `예` ➔ 사용자가 삭제 요청 가능한지: `예`
     - **개인정보(계정)**: 사용자 식별자, 이메일(소셜 로그인 시) ➔ 수집 목적: `계정 관리`
9. **정부 앱**:
   - `아니요`
10. **금융 기능**:
    - `해당 없음`

---

### 3단계: 기본 스토어 등록정보 작성
좌측 메뉴의 **[스토어 설정]** ➔ **[기본 스토어 등록정보]**:

1. **간단한 설명 (최대 80자)**:
   > 내 위치 주변 가볼 만한 곳과 최적의 당일치기 여행 코스를 추천하는 스마트 여행 지도 서비스
2. **자세한 설명 (최대 4,000자)**:
   > 위치 기반 여행 일정 및 맛집 지도 서비스, '하루여행'입니다.\n\n[주요 기능]\n- 실시간 내 위치 주변 추천 장소 탐색\n- 클릭 한 번으로 완성되는 여행 동선 최적화\n- 다양한 테마의 추천 코스 둘러보기 및 내 여행으로 담기\n- 네이버 지도 도보/차량 길찾기 원클릭 연동\n- 한국어, 영어, 일본어, 중국어 다국어 완벽 지원
3. **그래픽 애셋 업로드**:
   - 앱 아이콘 (512x512 PNG)
   - 그래픽 이미지 (1024x500 PNG)
   - 휴대전화 스크린샷 (최소 2장 이상)

---

### 4단계: 번들(AAB) 업로드 및 출시 트랙 선택

#### ⚠️ 개인 개발자 계정 필수 조건 (20인 비공개 테스터)
> 개인 개발자 계정의 경우, **프로덕션(정식 출시)을 바로 할 수 없으며**, 최소 **20명의 테스터가 14일 이상 연속으로 비공개 테스트에 참여**해야 프로덕션 신청 권한이 열립니다.

1. **릴리스 생성**:
   - 좌측 메뉴 **[출시]** ➔ **[비공개 테스트]** (또는 내부 테스트) ➔ **[새 버전 만들기]**
2. **AAB 파일 업로드**:
   - `oneday-trip-app/app/build/outputs/bundle/release/app-release.aab` 드래그 앤 드롭
3. **출시 노트 작성**:
   - 예: `<ko-KR>하루여행 첫 번째 버전 출시 (위치 기반 코스 추천 및 지도 연동)</ko-KR>`
4. **저장 및 버전 검토** ➔ **[출시 시작]**

---

### 5단계: 심사 제출 및 승인

- **심사 소요 시간**: 통상 **1영업일 ~ 3영업일** (신규 계정이나 첫 등록 시 최대 7일까지 소요 가능)
- **심사 거절(Rejection) 방지 팁**:
  1. 웹뷰 로딩 시 빈 흰 화면(White-out)이 나오지 않도록 배포 URL(`https://oneday-trip.vercel.app`) 정상 작동 필수
  2. 위치 권한 요청 시 왜 위치 권한이 필요한지 안내 팝업이 뜨는지 확인
  3. 테스트 계정으로 로그인했을 때 오류가 없어야 함
