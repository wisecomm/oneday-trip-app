# 🧪 Android & iOS 앱 테스트 가이드

하루여행(OneDay Trip) 앱의 출시 전 테스트 트랙별 절차, 요건 및 운영 가이드입니다.

---

## 📌 플랫폼별 테스트 트랙 한눈에 보기

| 구분 | Google Play (Android) | Apple App Store (iOS) |
| :--- | :--- | :--- |
| **빠른 자가 검증** | **내부 테스트 (Internal Testing)**<br>- 검수 없음 (즉시 배포)<br>- 최대 100명 | **TestFlight 내부 테스트**<br>- 애플 검수 없음 (즉시 배포)<br>- 개발팀원 최대 100명 |
| **출시 전 필수/외부 테스트** | **비공개 테스트 (Closed Testing)**<br>- 구글 검수 필수 (1~3일)<br>- **개인 계정: 20명 14일 의무** | **TestFlight 외부 테스트**<br>- 베타 심사 있음 (1일 내외)<br>- 최대 10,000명 (기간 제한 없음) |
| **정식 출시 전 제약** | **20명 테스터가 14일간 참여 유지 필수** | **인원/기간 의무 조건 없음** (즉시 심사 제출 가능) |
